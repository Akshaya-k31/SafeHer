🛡️ SafeHer

SafeHer is a safety-first navigation system that helps users choose the safest route instead of just the fastest one.

❗ Problem

Existing navigation apps focus only on speed and distance, ignoring personal safety risks like unsafe areas, poor lighting, and isolated routes.

💡 Solution

SafeHer recommends safer routes by analyzing:

Crime data
Lighting conditions
Crowd density
User-reported unsafe locations

⚙️ Tech Stack
Frontend: React, Tailwind CSS
Backend: Flask (Python)
Data: Open datasets + user reports

📊 Features
Safe route suggestion
Report unsafe locations
Safety heatmap
Simple and user-friendly interface

🎯 Tagline
“The safest way home, designed for her.”
