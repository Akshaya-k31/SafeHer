## SafeHer – Project Abstract

SafeHer is an AI-assisted women safety navigation platform designed to improve personal security during travel by prioritizing safety over speed. Unlike traditional navigation systems that optimize routes based only on distance and time, SafeHer analyzes multiple real-world risk factors such as crime density, street lighting conditions, traffic intensity, police proximity, and community safety reports to generate safer travel routes.

The system allows users to enter a source and destination, after which it evaluates multiple route options and assigns each a dynamic safety score. These routes are visually represented on an interactive map using color-coded paths, where green indicates the safest route, orange represents a balanced route, and red indicates a faster but relatively unsafe route. In addition, SafeHer provides a safety heatmap overlay that highlights high-risk zones based on historical data and user-generated reports.

The platform also includes a bus stop safety feature that ranks nearby public transport stops based on lighting, crowd density, and safety scores, helping users choose safer boarding points. Users can further contribute to the system by reporting unsafe locations, which are stored and used to improve safety analysis over time.

SafeHer is built using a modern web technology stack with a React-based frontend, a Flask backend, MySQL database integration, and Google Maps APIs for geospatial visualization. The system demonstrates how data-driven safety analytics can enhance urban mobility and support safer travel decisions, especially for women and vulnerable users.
